A one-line warning label for a time machine, written to get the biggest laugh in 120 characters or fewer. `main.py` writes the label to `/output/entry.txt`:

> WARNING: Never give your grandfather a ride home. Stranding him is covered; becoming your own ancestor is not.

The stranded-ancestor hazard is the joke, delivered deadpan like an insurance notice, with the twist held to the last words. Run it with `python3 main.py`.
